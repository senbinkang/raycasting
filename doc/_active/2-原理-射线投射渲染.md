# 射线投射渲染原理

> 2026-07-06

## 核心问题

如何将一张 20×20 的二维网格地图，渲染成 640×400 像素的第一人称 3D 画面？

答案：**DDA 射线投射（Digital Differential Analyzer Raycasting）**——从玩家视角出发，对屏幕每一列发射一条射线，检测射线在 2D 网格中击中哪个墙壁格子，根据命中距离计算该列墙体的屏幕高度，再采样纹理逐像素着色。

## 渲染流水线

```
每帧 draw() 调用：
  1. _drawBg()      地板 + 天花板（逐行纹理投射）
  2. _drawWall()    墙体（DDA 射线投射）
  3. _drawSprites() 精灵（变换投影 + zBuffer 遮挡）
  4. _drawProjectiles() 敌人子弹
  5. putImageData() 一次性写入 Canvas
```

全部渲染在单个 `ImageData` 上完成，最后一次性 `putImageData`，避免多次 Canvas API 调用的性能开销。

## 一、墙体渲染：DDA 算法

### 1.1 相机模型

玩家状态包含两个关键向量：

```
dir(方向向量)    = (dirX, dirY)     —— 玩家面朝方向，长度=1
plane(平面向量)  = (planeX, planeY) —— 垂直于 dir，长度决定 FOV
```

FOV（视场角）由 plane 长度决定：`FOV = 2 × atan(|plane| / |dir|)`。代码中 `|plane|=0.66, |dir|=1`，得 FOV ≈ 66.8°。

屏幕宽度 640px，每一列 x 对应一个 `cameraX`：

```
cameraX = 2 × x / width - 1    范围：[-1, 1]
```

对于第 x 列，射线方向：

```
rayDirX = dirX + planeX × cameraX
rayDirY = dirY + planeY × cameraX
```

cameraX=-1 时射线偏向最左，cameraX=0 时射线在正前方，cameraX=1 时偏向最右。

### 1.2 DDA 步进

DDA 算法的核心思想：不检测射线经过的每一个点，而是**直接跳到下一个网格边界**。

```
设定：
  mapX, mapY   = 当前所在格子坐标
  deltaDistX   = |1 / rayDirX|   射线在 X 方向跨越一格需要的距离
  deltaDistY   = |1 / rayDirY|   射线在 Y 方向跨越一格需要的距离
  sideDistX    = 从玩家位置到下一个 X 网格边界的距离
  sideDistY    = 从玩家位置到下一个 Y 网格边界的距离

每一步：
  if sideDistX < sideDistY:
    sideDistX += deltaDistX
    mapX += stepX      (stepX = ±1)
    side = 0           (0=命中垂直墙, 1=命中水平墙)
  else:
    sideDistY += deltaDistY
    mapY += stepY
    side = 1

  检查 worldMap[mapY][mapX] 是否 > 0（是墙）
  若是，停止；若否，继续步进
```

DDA 步进的本质是：比较 sideDistX 和 sideDistY，"谁小就先到达谁的边界"，然后跳到下一个格子。每次只走一格，保证不漏检。

### 1.3 鱼眼修正

不修正时，屏幕边缘的射线比中央的射线更长（因为斜射），导致墙壁边缘被拉伸变形（鱼眼效应）。

修正方法：用**垂直距离**（perpDist）替代射线实际长度。

```
perpDist = (side === 0) ? sideDistX - deltaDistX : sideDistY - deltaDistY
```

这个值正好等于玩家到墙面的垂直距离，消除了鱼眼效应。同时写入 zBuffer，供精灵遮挡判定使用。

### 1.4 墙高计算

```
lineHeight = height / perpDist   （近大远小：距离越远，屏幕高度越小）
drawStart  = -lineHeight / 2 + height / 2
drawEnd    = drawStart + lineHeight
```

### 1.5 纹理采样

算出墙上命中点的水平位置 `wallX`（0~1），映射到纹理列：

```
texX = floor(wallX × 64)    // 64 = 纹理宽度
```

方向修正：根据射线方向和命中的面（side），翻转 texX 确保纹理不镜像：
```
if (side === 0 && rayDirX > 0) texX = 63 - texX
if (side === 1 && rayDirY < 0) texX = 63 - texX
```

对屏幕该列的每个像素，计算 texY（从 drawStart 到 drawEnd 映射到 0~63），取纹理列的对应像素颜色。

### 1.6 光照模型

三个因子叠加：

| 因子 | 公式 | 效果 |
|------|------|------|
| 方向光 | `0.65 + 0.35 × dot(rayDir, wallNormal)` | 正对的面更亮 |
| 侧面暗化 | `side === 1 ? 0.8 : 1.0` | 水平墙略暗 |
| 距离衰减 | `1 / (1 + 0.02 × dist²)` | 远处渐暗 |
| 手电筒 | `(1 - |cameraX| × 1.2)² × 70` | 屏幕中央更亮 |

## 二、地板/天花板渲染

与墙体逐列投射不同，地板和天花板是**逐行投射**。

### 2.1 核心公式

对于屏幕上每一行 y（0 到 height/2 为天花板，height/2 到 height 为地板），该行对应的世界距离：

```
rowDistance = posZ / p
  其中 p = |y - height/2|（行到水平中线的像素距离）
       posZ = height × 0.5（虚拟相机高度）
```

行距离确定后，用步进方式遍历该行每个 x 列：

```
floorX = posX + rowDistance × rayDirLeft   ← 从左边界开始
floorY = posY + rowDistance × rayDirLeft
stepX  = rowDistance × (rayDirRight - rayDirLeft) / width
stepY  = rowDistance × (rayDirRight - rayDirLeft) / width

for x in 0..width:
  texX = |floorX - floor(floorX)| × 64
  texY = |floorY - floor(floorY)| × 64
  采样地板纹理 → 写入 pixels
  floorX += stepX; floorY += stepY
```

### 2.2 天花板同理

天花板用上半部分屏幕行，公式完全相同，只是使用天花板纹理。

## 三、精灵渲染

精灵（敌人、物品）是 2D 贴图，通过**透视投影变换**投影到屏幕上。

### 3.1 投影变换

```
spriteX = sprite.worldX - player.posX
spriteY = sprite.worldY - player.posY

// 逆相机矩阵变换
invDet = 1 / (planeX × dirY - dirX × planeY)
transformX = invDet × (dirY × spriteX - dirX × spriteY)   // 精灵在相机空间的 X
transformY = invDet × (-planeY × spriteX + planeX × spriteY) // 精灵在相机空间的深度

screenX    = (width / 2) × (1 + transformX / transformY)  // 屏幕 X 坐标
spriteHeight = |height / transformY|                       // 屏幕高度（近大远小）
spriteWidth  = |width / transformY|                        // 屏幕宽度
```

`transformY` 即精灵到相机的深度距离，决定了屏幕上的大小。

### 3.2 zBuffer 遮挡

每个精灵的每个像素写入前，检查 zBuffer：

```javascript
if (zBuffer[stripe] < transformY) continue  // 该列有更近的墙，跳过
```

这确保了墙壁挡在精灵前面时，精灵像素不会被绘制。

### 3.3 渲染排序

精灵按距离**从远到近**排序后再绘制，确保近处精灵遮挡远处精灵。

### 3.4 透明/受伤闪烁

- 透明像素（alpha < 32）跳过不绘制
- 受伤闪白：`hitFlashTimer > 0` 时 RGB 各 +150

## 四、雾效

统一的后处理效果，墙体、地板、天花板都应用：

```
fogStart = 4, fogFull = 14   // 4 格开始起雾，14 格完全被雾覆盖

fogAlpha = clamp((perpDist - fogStart) / (fogFull - fogStart), 0, 1)
最终颜色 = 原始颜色 × (1 - fogAlpha) + 雾色 × fogAlpha
```

雾色 RGB(80, 80, 100) 呈灰蓝色，远处物体逐渐融入雾中，营造场景深度感和压抑氛围。

## 五、性能优化策略

1. **单 ImageData 全帧写入**：所有渲染（墙+地板+天花板+精灵+子弹）写入同一个 ImageData，最后一次性 `putImageData`，消除多次 Canvas API 调用
2. **纹理列预缓存**：构造时预加载所有墙体纹理列到 `Uint8ClampedArray`（去掉 alpha 通道），渲染时纯数组读取
3. **零 fillRect / getImageData**：每帧渲染全程纯 CPU 数组运算，不调用 Canvas 2D API
4. **Float32Array zBuffer**：比普通数组更紧凑
5. **雾效早退**：行级判断 `fogAlpha >= 1` 时直接填雾色跳过纹理采样
