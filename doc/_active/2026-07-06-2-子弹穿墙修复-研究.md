# 子弹穿墙 + 射程问题 — 研究

> 2026-07-06

## 一、问题现象

1. 玩家子弹可以穿透墙壁击中墙后的敌人
2. 敌人子弹射程过长，没有在合理距离内消失

## 二、玩家子弹：命中检测机制分析

### 2.1 当前实现

`Weapon.fire()`（`game/Weapon.js:34-75`）使用**屏幕空间命中检测**：

```
for 每个存活的敌人:
  1. 计算敌人在玩家相机空间的变换坐标 (transformX, transformY)
  2. transformY 即敌人距离（深度）
  3. 判断 transformY <= 0.05（在玩家背后）→ 跳过
  4. 判断 transformY > maxRange(10) → 跳过
  5. 计算 spriteScreenX（敌人在屏幕上的 X 位置）
  6. 判断 spriteScreenX 是否在准星范围内（width/2 附近）
  7. 选距离最近的作为命中目标
```

### 2.2 缺陷

**完全没有视线检测**。步骤 3-4 只检查了距离和屏幕位置，从未验证玩家到敌人之间是否有墙体阻隔。只要敌人在准星方向和 10 格范围内，即使中间隔了多堵墙也会被判定为命中。

### 2.3 修复思路

在步骤 6 和步骤 7 之间插入**射线-墙体碰撞检测**：从玩家位置向敌人位置发射射线，检测射线路径上是否碰到墙体。若碰墙，则敌人被遮挡，跳过。

可选方案：

| 方案 | 描述 | 优缺点 |
|------|------|--------|
| A: DDA 步进 | 从玩家向敌人做 DDA 步进，检测路径上是否有墙 | 最精确，但代码量较大 |
| B: 离散采样 | 沿玩家→敌人方向均匀采样 N 个点，检查每个点是否在墙内 | `Sprite.js:86-93` 已有同款实现（`canSee`），可直接复用，精度足够 |

**推荐方案 B**：与现有敌人 AI 的视线检测（`Sprite.js` 的 `canSee` 逻辑）保持一致，采样点数 `max(2, floor(dist * 4))`，足以覆盖 20×20 地图的精度需求。

## 三、敌人子弹：射程检测分析

### 3.1 当前实现

`GameScene.update()`（`game/GameScene.js:205-227`）：

```javascript
// 碰墙消失（第 211 行）—— 这部分是正确的
let mx = Math.floor(p.x), my = Math.floor(p.y)
if (...this.bg.worldMap[my][mx] !== 0) {
    this.projectiles.splice(i, 1)  // ✓ 碰到墙会消失
    continue
}
// 超出范围消失（第 216-217 行）
let pdx = p.x - this.player.position.x, pdy = p.y - this.player.position.y
if (Math.sqrt(pdx * pdx + pdy * pdy) > 15) {  // ✗ 15 格太长，且基准是玩家位置
    this.projectiles.splice(i, 1)
}
```

### 3.2 缺陷

- **射程基准错误**：以玩家当前位置为基准计算距离。若玩家移动远离子弹，子弹射程会"缩短"；若玩家向子弹方向移动，射程会"延长"。正确做法应以子弹发射点为基准。
- **射程值偏大**：15 格几乎覆盖大半张地图，应改为 10 格。

### 3.3 修复思路

子弹创建时（`Sprite.js:100`）记录发射点坐标：
```javascript
return { projectile: { x: this.x, y: this.y, ndx, ndy, speed: 4, damage: 15,
                        originX: this.x, originY: this.y } }
```

射程检测改为：
```javascript
let odx = p.x - p.originX, ody = p.y - p.originY
if (Math.sqrt(odx * odx + ody * ody) > 10) {  // 从发射点算 10 格
```

## 四、敌人子弹：碰墙检测的正确性

`GameScene.js:211` 的碰墙检测 `this.bg.worldMap[my][mx] !== 0` 是正确的，敌人子弹碰到墙体格子确实会消失。**这部分无需修改。**
