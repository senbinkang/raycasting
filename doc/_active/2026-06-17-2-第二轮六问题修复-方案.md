## 二、逐项方案

### 2.1 修复穿墙（`Player.js`）

**三管齐下**：

a) `collisionRadius` 从 0.35 改为 **0.4**

b) 分轴检测原子化：先分别计算 X/Y 是否可移动，再一起应用，避免 X 轴移动后污染 Y 轴判断

```javascript
tryMove(dx, dy, step) {
    let len = Math.sqrt(dx * dx + dy * dy)
    if (len < 0.0001) return
    dx = dx / len
    dy = dy / len
    let r = this.collisionRadius

    let newX = this.position.x + dx * step
    let newY = this.position.y + dy * step
    let checkX = newX + Math.sign(dx) * r
    let checkY = newY + Math.sign(dy) * r

    let canMoveX = this.cellIsEmpty(checkX, this.position.y) &&
        this.cellIsEmpty(checkX, this.position.y + r * 0.6) &&
        this.cellIsEmpty(checkX, this.position.y - r * 0.6) &&
        !this._collidesBlockingSprite(newX, this.position.y)

    let canMoveY = this.cellIsEmpty(this.position.x, checkY) &&
        this.cellIsEmpty(this.position.x + r * 0.6, checkY) &&
        this.cellIsEmpty(this.position.x - r * 0.6, checkY) &&
        !this._collidesBlockingSprite(this.position.x, newY)

    if (canMoveX) this.position.x = newX
    if (canMoveY) this.position.y = newY
}
```

c) 事后修正：移动完成后，如果玩家中心点落入墙格，回退到最近的合法位置

### 2.4 小地图射线（`Player.js` `draw()`）

在 `drawDirArrow()` 之后新增 `drawRays()`：从玩家位置出发，在自身 FOV（66°）范围内每隔 10° 发一条 DDA 射线，无限延伸直到撞墙或出地图边界，在小地图上画半透明黄色线段。

```javascript
drawRays() {
    let ctx = this.game.context
    let unit = this.unit
    let startX = this.position.x * unit
    let startY = this.position.y * unit
    let rayColor = new Color(255, 255, 100, 0.3)
    
    // FOV = 2 * atan(planeLen)，planeLen = 0.66，FOV ≈ 66°
    // 中心方向 dir，左右各 33°
    let centerAngle = Math.atan2(this.dirY, this.dirX)
    let halfFov = Math.atan2(0.66, 1.0)  // ≈ 33.4°
    let totalSteps = Math.round(2 * halfFov / (10 * Math.PI / 180))  // ≈ 6-7 条线
    if (totalSteps < 1) totalSteps = 1
    
    for (let i = 0; i <= totalSteps; i++) {
        let angle = centerAngle - halfFov + (2 * halfFov * i / totalSteps)
        let rx = Math.cos(angle), ry = Math.sin(angle)
        // DDA 简版：沿射线方向步进，直到撞墙或出界
        let dist = 0.1
        let maxDist = 20
        let hit = false
        while (dist < maxDist) {
            let cx = Math.floor(this.position.x + rx * dist)
            let cy = Math.floor(this.position.y + ry * dist)
            if (cx < 0 || cy < 0 || cx >= this.columns || cy >= this.lines) break
            if (this.worldMap[cy][cx] > 0 && this.worldMap[cy][cx] < 101) { hit = true; break }
            dist += 0.05
        }
        drawLine(ctx, rayColor, startX, startY,
            startX + rx * dist * unit, startY + ry * dist * unit)
    }
}
```

### 2.6 敌人不重叠（`game/SpriteManager.js`）

在 `update()` 中，精灵 AI 更新完成后，对所有活着的敌人两两检测距离，距离 < 0.5 时互相推开：

```javascript
// 敌人间分离力
let enemies = this.sprites.filter(s => s.alive && s.type === 'enemy')
for (let i = 0; i < enemies.length; i++) {
    for (let j = i + 1; j < enemies.length; j++) {
        let dx = enemies[j].x - enemies[i].x
        let dy = enemies[j].y - enemies[i].y
        let dist = Math.sqrt(dx * dx + dy * dy)
        if (dist < 0.5 && dist > 0.001) {
            let push = (0.5 - dist) / 2
            let nx = dx / dist, ny = dy / dist
            enemies[i].x -= nx * push
            enemies[i].y -= ny * push
            enemies[j].x += nx * push
            enemies[j].y += ny * push
        }
    }
}
```
