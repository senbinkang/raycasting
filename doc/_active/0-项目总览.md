# Raycasting 项目总览

> 当前版本：**2026-07-06**

## 原理文档

| 文件 | 内容 |
|------|------|
| `2-原理-音频合成.md` | Web Audio API 程序化合成音效/BGM，零音频文件 |
| `2-原理-程序化纹理.md` | Canvas 程序化生成全部纹理（墙/地板/敌人/物品） |

## 文件结构（14 个 JS + 1 个 HTML）

```
raycasting/
├── index.js                    入口：创建 Game + GameScene，启动主循环
├── raycasting.html             HTML 结构：3 个 canvas + 操作提示
├── utils.js                    Vec / Color 类 + drawLine/drawRect/drawArc
├── textures.js                 TextureManager：程序化纹理（墙/地板/天花板/敌人/物品）
├── Background.js               20×20 地图 + 小地图绘制
├── Player.js                   玩家：移动、碰撞、旋转、HP、拾取
└── game/
    ├── Game.js                 主循环、输入处理、HUD、射击触发、暂停
    ├── GameScene.js            场景状态机（菜单/游戏中/死亡/胜利）、波次管理、敌人生成、子弹管理
    ├── Screen.js               3D DDA 射线投射渲染（墙 + 地板天花板 + 精灵 + 子弹 + 雾效 + 光照）
    ├── OverlayScreen.js        标题画面 / 死亡画面 / 胜利画面
    ├── Sprite.js               精灵：敌人 AI（追踪/巡逻/远程/视线检测/接触伤害）+ 物品
    ├── SpriteManager.js        精灵管理：更新、分离力、小地图绘制
    ├── Weapon.js               手枪渲染 + 屏幕空间命中判定 + 后坐力
    └── AudioManager.js         Web Audio API 合成音效（射击/命中/死亡/脚步/BGM/玩家受伤）
```

## 三个 Canvas

| Canvas | 尺寸 | 用途 |
|--------|------|------|
| `id-canvas` | 400×400 | 小地图 |
| `id-canvas-image` | 640×400 | 3D 画面 |
| `id-canvas-overlay` | 640×400 | 标题/死亡/胜利覆盖层 |

## 已实现的功能

- 标准 DDA 射线投射 + 鱼眼修正
- 程序化纹理：4 种墙 + 地板天花板 + 5 种敌人 + 医疗包
- 精灵系统：zBuffer 遮挡排序 + 距离衰减
- 雾效 + 方向光 + 手电筒增强
- 全帧 ImageData 批量写入（性能优化）
- 5 种敌人类型（普通/快速/坦克/幽灵/远程），不同速度/HP，接触伤害统一 10
- 不同敌人不同分数：快速 50 / 普通 100 / 幽灵 150 / 坦克 200 / 远程 175
- 计分系统 + 波次递增（4→5→6→7→8 敌）+ 5 波通关
- 医疗包拾取回血（+30，满血不捡），每波重生 3 个
- 标题/死亡/胜利三个画面
- 玩家 7 点采样 + 对角点碰撞
- 敌人 5 点采样 + 对角点碰撞 + 分离力
- 接触伤害：首次立即扣血 + 每 3 秒再次扣血（不依赖视线检测）
- 玩家受伤后 2 秒无敌 + 血条闪烁
- HUD：右上 FPS/位置/朝向/分数/波次，左下血条 + HP 数值
- 音效：射击/命中/敌人死亡/脚步声/BGM/玩家受伤（Web Audio API 合成）
- 不同敌人不同死亡音效：快速尖锐 / 坦克低沉
- 敌人巡逻行为：看不见玩家时随机走动
- 远程敌人（第 5 种）：绿色炮管造型，保持距离射击子弹
- 敌人受伤闪白反馈
- 波次提示：屏幕中央"第 X 波"大字渐隐
- P 键暂停：灰色遮罩 + PAUSED 文字
- 最高分记录：localStorage 持久化，HUD + 结束画面显示，破纪录提示

## 游戏玩法

第一人称射击，在 20×20 地图中消灭敌人、拾取医疗包，撑过 5 波攻击。

- **移动**：WASD/↑↓ 在地图内移动，鼠标或 ←→ 旋转视角
- **射击**：鼠标左键或 Space 开火，命中敌人扣 50 血
- **敌人**：5 种类型，追踪/远程攻击，碰到扣 10 血

| 类型 | 颜色 | HP | 速度 | 几枪死 | 分数 | 备注 |
|------|------|-----|------|--------|------|------|
| 快速 | 橙 | 50 | 3.0 | 1 | 50 | |
| 普通 | 红 | 100 | 1.5 | 2 | 100 | |
| 幽灵 | 青 | 150 | 1.2 | 3 | 150 | |
| 坦克 | 紫 | 200 | 0.6 | 4 | 200 | |
| 远程 | 绿 | 80 | 0.8 | 2 | 175 | 保持距离射击子弹 |
- **医疗包**：走到旁边自动拾取，回复 30 血（满血不捡）
- **无敌**：受伤后 2 秒内不再受伤，血条闪烁提示
- **波次**：每波敌人全灭后自动进入下一波，敌人数递增（4→5→6→7→8）

## 胜利条件

消灭第 5 波全部敌人后显示胜利画面。

## 失败条件

HP 降至 0，显示死亡画面。
