# Raycasting 项目总览

> 当前版本：**2026-06-29**

## 文件结构（14 个 JS + 1 个 HTML）

```
raycasting/
├── index.js                    入口：创建 Game + GameScene，启动主循环
├── raycasting.html             HTML 结构：3 个 canvas + 操作提示
├── utils.js                    Vec / Color 类 + drawLine/drawRect/drawArc
├── textures.js                 TextureManager：程序化纹理（墙/地板/天花板/敌人/物品）
├── Background.js               20×20 地图 + 小地图绘制
├── Player.js                   玩家：移动、碰撞、旋转、HP、拾取
└── game/
    ├── Game.js                 主循环、输入处理、HUD、射击触发
    ├── GameScene.js            场景状态机（菜单/游戏中/死亡/胜利）、波次管理、敌人生成
    ├── Screen.js               3D DDA 射线投射渲染（墙 + 地板天花板 + 精灵 + 雾效 + 光照）
    ├── OverlayScreen.js        标题画面 / 死亡画面 / 胜利画面
    ├── Sprite.js               精灵：敌人 AI（追踪 + 视线检测 + 接触伤害）+ 物品
    ├── SpriteManager.js        精灵管理：更新、分离力、小地图绘制
    ├── Weapon.js               手枪渲染 + 屏幕空间命中判定 + 后坐力
    └── AudioManager.js         Web Audio API 合成音效（射击/受伤/死亡/脚步/BGM）
```

## 三个 Canvas

| Canvas | 尺寸 | 用途 |
|--------|------|------|
| `id-canvas` | 400×400 | 小地图 |
| `id-canvas-image` | 640×400 | 3D 画面 |
| `id-canvas-overlay` | 640×400 | 标题/死亡/胜利覆盖层 |

## 已实现的功能

- 标准 DDA 射线投射 + 鱼眼修正
- 程序化纹理：4 种墙 + 地板天花板 + 4 种敌人 + 医疗包
- 精灵系统：zBuffer 遮挡排序 + 距离衰减
- 雾效 + 方向光 + 手电筒增强
- 全帧 ImageData 批量写入（性能优化）
- 4 种敌人类型（普通/快速/坦克/幽灵），不同速度/HP/伤害
- 计分系统 + 波次递增 + 5 波通关
- 医疗包拾取回血
- 标题/死亡/胜利三个画面
- 玩家 7 点采样 + 对角点碰撞
- 敌人 5 点采样 + 对角点碰撞 + 分离力
- 接触伤害：首次立即扣血 + 每 3 秒再次扣血
- 玩家受伤 0.5 秒无敌
- 音效：射击/命中/敌人死亡/脚步声/BGM（Web Audio API 合成）

## 操作模式

### 纯键盘
| 按键 | 功能 |
|------|------|
| W/S | 前进/后退 |
| A/D/Q | 左右平移 |
| ←/→ | 左右旋转 |
| Space | 射击 |
| Shift | 加速跑 |
| Enter/Space | 开始/重开 |

### 键盘 + 鼠标
| 操作 | 功能 |
|------|------|
| W/S | 前进/后退 |
| A/D/Q | 左右平移 |
| 鼠标移动 | 旋转视角（点击画面锁定） |
| 鼠标左键/Space | 射击 |
| Shift | 加速跑 |
| Esc | 解除鼠标锁定 |
