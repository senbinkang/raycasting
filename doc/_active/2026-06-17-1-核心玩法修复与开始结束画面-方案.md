## 二、阶段一：核心玩法修复

### 2.1 修复射击系统（`game/Weapon.js`）

**命中判定重写**（替代第 80-106 行的错误公式）：

正确的命中判定逻辑：
1. 对每个活着的敌人，将其世界坐标变换到屏幕空间（与 Sprite 绘制相同的逆矩阵变换）
2. 得到 `transformX`（屏幕水平偏移）、`transformY`（深度）
3. 计算 sprite 在屏幕上的 X 中心：`spriteScreenX = (width/2) * (1 + transformX / transformY)`
4. 按距离排序，取最近的、且 spriteScreenX 在准星范围内（如屏幕中心的 ±spriteWidth*0.4 范围内）的敌人
5. 限制最大射程（10 格），超过射程不命中
6. 同时检查 zBuffer：射线碰到的墙的距离必须 > transformY（敌人在墙前面才能命中）

**冷却 + 后坐力 + 音效**：
- `fire()` 命中时设置 `this.cooldown = this.cooldownTime`
- `fire()` 开火时设置 `this.recoil = 1`
- `fire()` 开火时调用 `window.audioManager.playShoot()`

**代码改动**（`Weapon.js` 第 36-108 行整段替换）：

```javascript
fire() {
    if (this.cooldown > 0) return null
    
    const player = this.player
    const width = 640   // canvasImage 宽度
    const maxRange = 10
    
    // 播放射击音效 + 后坐力
    if (window.audioManager) window.audioManager.playShoot()
    this.recoil = 1
    this.cooldown = this.cooldownTime
    
    if (!this.spriteManager) return null
    
    let bestHit = null
    let bestDist = Infinity
    
    for (let s of this.spriteManager.sprites) {
        if (!s.alive || s.type !== 'enemy') continue
        
        let spriteX = s.x - player.position.x
        let spriteY = s.y - player.position.y
        
        let invDet = 1.0 / (player.planeX * player.dirY - player.dirX * player.planeY)
        let transformX = invDet * (player.dirY * spriteX - player.dirX * spriteY)
        let transformY = invDet * (-player.planeY * spriteX + player.planeX * spriteY)
        
        if (transformY <= 0.05) continue   // 背后
        if (transformY > maxRange) continue  // 超出射程
        
        // 变换到屏幕坐标
        let spriteScreenX = Math.floor((width / 2) * (1 + transformX / transformY))
        let spriteWidth = Math.abs(Math.floor(width / transformY))
        
        // 准星范围：屏幕中心 ± sprite 宽度的 35%
        let hitRange = Math.max(spriteWidth * 0.35, 8)
        let centerX = width / 2
        if (Math.abs(spriteScreenX - centerX) < hitRange && transformY < bestDist) {
            bestDist = transformY
            bestHit = s
        }
    }
    
    return bestHit
}
```

**敌人侧**（`game/Sprite.js` `update()` 第 82-100 行）：

```javascript
// 敌人碰撞（Sprite.js update 替换移动部分）
let r = this.radius || 0.2
let moveX = this.x + ndx * this.speed * dt
let moveY = this.y + ndy * this.speed * dt

// X 轴：用 radius 做边缘检测
let checkX = moveX + Math.sign(ndx) * r
if (cellIsEmptyForSprite(checkX, this.y, bg)) {
    this.x = moveX
}
// Y 轴
let checkY = moveY + Math.sign(ndy) * r
if (cellIsEmptyForSprite(this.x, checkY, bg)) {
    this.y = moveY
}
```

## 三、阶段二：开始/结束画面

### 3.1 HTML 新增独立 canvas

`raycasting.html` 中新增第三个 canvas：
```html
<canvas id="id-canvas-overlay" width="640" height="400"></canvas>
```
与 3D 画布等大，叠放在 3D 画布上方（CSS absolute 定位）。游戏运行时隐藏，菜单/结算时显示。

### 3.2 游戏状态机（`game/GameScene.js` 或新文件 `game/GameState.js`）

引入状态：
- `menu` → 显示标题画面
- `playing` → 正常运行
- `gameover` → 死亡画面
- `win` → 通关画面

状态转换：
- `menu` → (按 Enter / Space / 点击) → `playing`
- `playing` → (player.hp ≤ 0) → `gameover`
- `playing` → (所有敌人 dead) → `win`
- `gameover` / `win` → (按 Enter / Space / 点击) → `playing`（重置游戏）

### 3.3 画面绘制（新文件 `game/OverlayScreen.js`）

绘制到独立的 overlay canvas：
- **标题画面**：游戏标题 + "按 Enter 开始游戏" + 操作说明
- **死亡画面**：红色 "YOU DIED" + "按 Enter 重新开始"
- **通关画面**：金色 "MISSION COMPLETE" + "按 Enter 重新开始"

键盘事件在 Game 中注册，点击事件绑定到 overlay canvas。

### 3.4 游戏重置机制

`GameScene` 需要支持 `reset()` 方法：重新初始化 Background / Player / SpriteManager / Weapon。
