# 2026-06-25 — Space键射击 + 接触伤害间隔 + 双模式操作说明

## 一、需求/问题
1. 增加键盘按键射击（Space 键），不只依赖鼠标左键
2. 敌人碰到玩家应立即掉血，持续接触每 3 秒再次掉血
3. 操作说明需区分"纯键盘"和"键盘+鼠标"两种模式

## 二、做了什么
- `Game.js`：weapon fire 条件增加 `|| this.keysdown[' ']`，按 Space 键触发射击，受相同冷却限制
- `game/Sprite.js`：新增 `contactTimer` 字段，首次触碰立即扣血并设 3 秒冷却，离开范围重置
- `raycasting.html`：重写操作提示，分纯键盘/键鼠两档
- `game/OverlayScreen.js`：标题画面同步分两行说明

## 三、操作模式（最终版）

### 纯键盘模式
| 按键 | 功能 |
|------|------|
| W/S | 前进/后退 |
| A/D/Q | 左右平移 |
| ←/→ | 左右旋转视角 |
| Space | 射击 |
| Shift | 加速跑 |
| Enter/Space | 开始/重开 |

### 键盘 + 鼠标模式
| 操作 | 功能 |
|------|------|
| W/S | 前进/后退 |
| A/D/Q | 左右平移 |
| 鼠标移动 | 旋转视角（点击 3D 画面锁定鼠标） |
| 鼠标左键 / Space | 射击 |
| Shift | 加速跑 |
| Esc | 解除鼠标锁定 |
| Enter/Space/点击 | 开始/重开 |

## 四、关键决策
- 射击键选 Space，与菜单"开始/重开"共用同一键，游戏中仅触发射击
- 接触伤害用敌人侧 `contactTimer` 而非玩家 `invincibleTimer`，独立计时互不干扰
- 离开触碰范围立即重置 contactTimer，重新触碰立即扣血
