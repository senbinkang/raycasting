# 2026-07-07 — AI 实时解说

## 一、需求/问题
给游戏添加 AI 实时解说功能：游戏事件触发 LLM 生成幽默吐槽风格的解说文本，通过浏览器 TTS 朗读出来。LLM 调用失败时降级到预设模板。目标是让 AI 解说成为游戏体验的核心亮点。

## 二、做了什么
- 新建 `CommentaryService.js`，实现事件优先级队列、LLM 文本生成（OpenAI 兼容 API）、模板兜底、Web Speech API TTS 播放、配置管理（localStorage），涉及文件：`game/CommentaryService.js`
- 在 GameScene / Game / Player 共 10 处添加解说事件钩子，涉及文件：`game/GameScene.js`、`game/Game.js`、`Player.js`
- HTML 添加可折叠设置面板（API Endpoint/Key/Model/TTS/音量），涉及文件：`raycasting.html`
- 初始化 CommentaryService UI 绑定，涉及文件：`index.js`
- 修复 `this.queue` 属性名冲突（数组 vs 方法），重命名为 `_eventQueue`

## 三、关键决策 / 踩过的坑
- **LLM 为主、模板兜底**：用 LLM 事件的 useLLM 控制，高频事件（击杀/受伤）只用模板避免延迟和费用
- **优先级中断**：最高优先级事件（死亡/胜利）可中断当前 TTS 播放，通过 `speechSynthesis.cancel()` 实现
- **JS 属性名冲突**：`this.queue = []` 遮蔽了原型方法 `queue()`，导致 `window.commentaryService.queue is not a function`，重命名为 `_eventQueue` 解决
- **DeepSeek 兼容**：API 调用使用 OpenAI 兼容格式，Endpoint/Model 可配置，默认填入 DeepSeek 值
