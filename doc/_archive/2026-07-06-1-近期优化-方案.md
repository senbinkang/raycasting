## 1. 巡逻行为

**Sprite 构造函数**：新增两个字段
```
this.patrolAngle = Math.random() * Math.PI * 2
this.patrolTimer = 2 + Math.random() * 2
```

**Sprite.update()**：`if (!canSee)` 改为走巡逻逻辑而非 return
- `patrolTimer -= dt`，到期后随机换角度（0~2π），重置为 2~4 秒
- 以 `speed * 0.4` 沿 patrolAngle 移动
- 复用现有分轴碰撞检测（与追踪移动相同）

## 2. 受伤反馈

**Sprite 构造函数**：`this.hitFlashTimer = 0`

**Sprite.takeDamage()**：`this.hitFlashTimer = 0.1`

**Sprite.update()**：`if (this.hitFlashTimer > 0) this.hitFlashTimer -= dt`

**Screen.js** 精灵绘制：取纹理像素后，若 `sprite.hitFlashTimer > 0`，将 RGB 混合白色（`r = min(255, r+150)` 等）

## 3. 波次提示

**GameScene**：`this.waveNotifyTimer = 0`

**GameScene._respawnEnemies()**：开头设 `this.waveNotifyTimer = 2.0`

**GameScene.update()**：`if (this.waveNotifyTimer > 0) this.waveNotifyTimer -= dt`

**Game.drawHUD()**：当 `scene.waveNotifyTimer > 0` 时，屏幕中央绘制"第 X 波"，透明度 = `min(1, waveNotifyTimer)`

## 4. 暂停功能

**GameScene**：`this.paused = false`

**Game.js keydown**：P 键切换 `this.scene.paused`（仅在 playing 状态有效）

**Game.update()**：`scene.paused` 时跳过逻辑更新，只做渲染

**Game.draw()**：`scene.paused` 时叠加半透明灰遮罩 + "PAUSED" 文字

## 5. 玩家受伤音效

**AudioManager.playPlayerHurt()**：低频（100Hz）+ 噪声短促音

**Player.takeDamage()**：调用 `window.audioManager?.playPlayerHurt()`

## 6. 不同死亡音效

**AudioManager.playEnemyDeath(type)**：type 参数取 enemy 的 textureIndex
- 203（快速）：起始频率 600Hz，0.15s 衰减
- 204（坦克）：起始频率 120Hz，0.5s 衰减，加低频噪声
- 其他：现有默认（300→60，0.3s）

**Game.js 第 156 行**：`playEnemyDeath(enemy.textureIndex)`

## 7. 远程敌人

**textures.js**：新增 `generateRangedEnemy()` — 纹理 206，绿色身体+炮管造型

**GameScene ENEMY_TYPES**：新增 `{ tex: 206, speed: 0.8, hp: 80, damage: 10, score: 175, ranged: true, shootInterval: 2.0 }`

**Sprite 构造函数**：`this.ranged = options.ranged || false`，`this.shootTimer = options.shootInterval || 2`

**Sprite.update()**：ranged 敌人走独立 AI 分支
- 能看见玩家且距离 > 4：原地不动，`shootTimer -= dt`，到期射击，返回子弹数据
- 距离 < 3：后退（远离玩家方向移动）
- 看不见玩家：巡逻（复用逻辑）

**GameScene**：`this.projectiles = []`
- update 中遍历 projectiles：移动、碰墙消失、碰玩家扣血
- Sprite.update 返回子弹时 push 到 projectiles

**Screen.js**：遍历 projectiles 渲染小亮点

## 8. 最高分

**GameScene**：
- `this.highScore = 0`
- init/reset 时 `_loadHighScore()`：localStorage.getItem('raycasting_highscore')
- 游戏结束/胜利时 `_checkHighScore()`：比较并 localStorage.setItem
- `this.isNewRecord = false`

**Game.drawHUD()**：SCORE 下方显示 `HI: xxxx`

**OverlayScreen**：死亡/胜利画面显示最高分 + 是否 NEW RECORD
