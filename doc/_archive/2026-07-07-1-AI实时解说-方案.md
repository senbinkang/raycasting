# AI 实时解说 — 执行方案

> 2026-07-07

## 决策回顾

| 决策项 | 选择 |
|--------|------|
| 文本生成 | 模板 + LLM，LLM 为主，模板兜底 |
| TTS | 浏览器内置 SpeechSynthesis |
| 风格 | 幽默吐槽 |
| 设置面板 | 页面底部可折叠 |

## 架构概览

```
事件源（GameScene / Game / Player）
    ↓  queue(eventType, context)
CommentaryService
    ├─ 优先级队列 + 冷却检查
    ├─ 文本生成：先调 LLM → 失败降级模板
    ├─ TTS 播放：SpeechSynthesis
    └─ 配置管理：localStorage 读写 API Key 等
```

新增 1 个文件，改动 5 个文件。

### 1.2 事件优先级 + 冷却表

```
    enemy_bullet_hit: { priority: 4, cooldown: 3,   useLLM: false },
    health_pickup:    { priority: 4, cooldown: 5,   useLLM: false },

    unpause:          { priority: 5, cooldown: 2,   useLLM: false },

```

数字越小优先级越高。priority 0 可以中断当前播放。

### 1.3 `queue(eventType, context)`

```js
queue(eventType, context) {
    if (!this.enabled) return
    const rule = PRIORITY[eventType]
    if (!rule) return

    // 冷却检查
    const now = performance.now() / 1000
    if (rule.cooldown > 0) {
        const last = this.cooldowns[eventType] || 0
        if (now - last < rule.cooldown) return
    }

    // 去重：如果已有同类型事件在队列中，跳过
    if (this.queue.some(e => e.type === eventType)) return
    // 如果正在等 LLM 的同类型事件，也跳过
    if (this._pendingLLM === eventType) return

    this.queue.push({ type: eventType, context, priority: rule.priority, useLLM: rule.useLLM })
    this.queue.sort((a, b) => a.priority - b.priority)
}
```

### 1.4 `update(dt)`

每帧由 GameScene 调用。

```js
update(dt) {
    if (this.queue.length === 0) return
    // 如果正在播放，检查是否可中断
    if (this._speaking) {
        const top = this.queue[0]
        if (top.priority === 0) {
            speechSynthesis.cancel()
            this._speaking = false
        } else {
            return  // 等当前播放完
        }
    }
    this._processNext()
}
```

### 1.5 `_processNext()`

```js
async _processNext() {
    if (this.queue.length === 0) return
    const event = this.queue.shift()
    const rule = PRIORITY[event.type]

    this.cooldowns[event.type] = performance.now() / 1000

    const text = await this._generateText(event.type, event.context)
    if (text) this._speak(text)
}
```

### 1.6 `_generateText(eventType, context)`

```js
async _generateText(eventType, context) {
    const rule = PRIORITY[eventType]
    if (rule.useLLM) {
        this._pendingLLM = eventType
        const llmText = await this._callLLM(eventType, context)
        this._pendingLLM = null
        if (llmText) return llmText
        // LLM 失败，降级模板
    }
    return this._getTemplate(eventType, context)
}
```

### 1.7 `_callLLM(eventType, context)`

```js
async _callLLM(eventType, context) {
    const config = this.loadConfig()
    if (!config.apiKey || !config.endpoint) return null

    const prompt = this._buildPrompt(eventType, context)
    try {
        const controller = new AbortController()
        const timeout = setTimeout(() => controller.abort(), 5000)

        const resp = await fetch(config.endpoint, {
            method: 'POST',
            headers: {
                'Content-Type': 'application/json',
                'Authorization': `Bearer ${config.apiKey}`
            },
            body: JSON.stringify({
                model: config.model || 'gpt-3.5-turbo',
                messages: [
                    { role: 'system', content: SYSTEM_PROMPT },
                    { role: 'user', content: prompt }
                ],
                max_tokens: 80,
                temperature: 0.9
            }),
            signal: controller.signal
        })
        clearTimeout(timeout)
        const data = await resp.json()
        return data.choices?.[0]?.message?.content?.trim() || null
    } catch (e) {
        return null
    }
}
```

### 1.11 TTS 播放

```js
_speak(text) {
    if (!this.ttsEnabled || !text) {
        if (!text) this._processNext()
        return
    }
    // 确保 voices 已加载
    const voices = speechSynthesis.getVoices()
    const zhVoice = voices.find(v => v.lang.startsWith('zh-CN')) ||
                    voices.find(v => v.lang.startsWith('zh'))

    const utter = new SpeechSynthesisUtterance(text)
    utter.lang = 'zh-CN'
    utter.rate = 1.05
    utter.pitch = 1.0
    utter.volume = this.ttsVolume
    if (zhVoice) utter.voice = zhVoice

    this._speaking = true
    utter.onend = () => {
        this._speaking = false
        this._processNext()  // 播放下一条
    }
    utter.onerror = () => {
        this._speaking = false
        this._processNext()
    }
    speechSynthesis.speak(utter)
}
```

## 六、改动文件：`game/GameScene.js` — 敌方子弹命中玩家

在 `update()` 的子弹碰玩家检测位置（约 225 行）：

```js
if (pdist < 0.5) {
    this.player.takeDamage(p.damage || 15)
    if (window.commentaryService) {
        window.commentaryService.queue('enemy_bullet_hit', {
            damage: p.damage || 15, hp: Math.ceil(this.player.hp), maxHp: this.player.maxHp
        })
    }
    this.projectiles.splice(i, 1)
}
```

注意：`player_hurt` 在 `Player.takeDamage()` 里也会触发，可能导致同一事件触发两次解说（近战接触伤害 和 远程子弹伤害 都会调 takeDamage）。需要在 `enemy_bullet_hit` 和 `player_hurt` 之间做区分。

**处理方式**：`Player.takeDamage()` 不区分伤害来源，所以 `player_hurt` 会在所有受伤时触发。`enemy_bullet_hit` 是额外的子弹命中通知。为避免重复，改为：
- 接触伤害（敌人近战）→ `Player.takeDamage()` 触发 `player_hurt`
- 子弹伤害 → `GameScene.update()` 触发 `enemy_bullet_hit`，且 `Player.takeDamage()` 不过来（通过参数控制）

最简单的做法：`Player.takeDamage()` 调 `player_hurt`，`enemy_bullet_hit` 不再单独触发。但如果想区分"被远程兵子弹打中"和"被近战敌人碰到"，可以给 takeDamage 加 source 参数。

**简化方案**：保留 `Player.takeDamage()` 中的 `player_hurt`，删除 `GameScene.update()` 中额外的 `enemy_bullet_hit`。两种受伤统一用 `player_hurt` 解说。
