# Raycasting 项目结构分析

> 分析日期：2026-07-09

## 一、项目定位

一个**纯 JavaScript（无框架/无构建工具）**的第一人称射击游戏，直接在浏览器打开 `raycasting.html` 即可运行。核心渲染基于 **DDA 射线投射算法**，不使用 WebGL——所有像素通过 CPU 计算后写入 Canvas `ImageData`。

## 二、架构总览

```
                     index.js (入口)
                         │
                    ┌────┼────┐
                    v         v
              Game.js    GameScene.js
            (主循环/I/O)  (场景状态机/波次)
               │  │            │
               │  └────────────┤
               v               v
         Player.js        Screen.js (3D渲染核心)
         (移动/碰撞)      (DDA + 纹理 + 精灵 + 雾效)
               │               │
               └───────┬───────┘
                       v
              Background.js  SpriteManager.js
              (地图数据)     (精灵AI/分离力)
```

**数据流**：`Game.runLoop()` 每帧计算 `deltaTime` → 驱动按键动作 (`doAction`) → 调用 `scene.update(dt)`（AI/子弹/碰撞） → 调用 `draw()`（墙体/地板/精灵/武器/HUD 按层绘制到 3 个 Canvas 上）。

## 三、三个 Canvas 分层渲染

| Canvas | 尺寸 | 绘制内容 |
|--------|------|---------|
| `id-canvas` | 400×400 | 小地图（墙体、网格线、坐标、玩家/敌人位置） |
| `id-canvas-image` | 640×400 | 3D 画面（墙体 DDA、地板天花板投射、精灵排序、子弹、雾效、手枪） |
| `id-canvas-overlay` | 640×400 | 标题画面 / 死亡画面 / 胜利画面 / 暂停遮罩 |

| `Screen.js` | 516 | **渲染核心**：DDA 射线投射（墙体纹理采样 + 鱼眼校正）+ 地板/天花板逐行投射 + 精灵绘制（按距离排序 + zBuffer 遮挡）+ 子弹绘制 + 雾效/方向光/手电筒。全帧一个 `ImageData` 批量写入，零 `fillRect`/`getImageData` 调用，纹理列/像素预先缓存 |

| `SpriteManager.js` | 69 | 精灵集合管理：每帧更新所有精灵 AI、敌人间分离力（防重叠）、玩家物品捡取触发、小地图精灵绘制（按类型着色） |
| `Weapon.js` | 142 | 手枪渲染（2D Canvas 绘制枪身）+ DDA 射击射线检测（屏幕空间命中判定 + 准星范围）+ 后坐力动画 + 连射冷却（0.18 秒） |
| `AudioManager.js` | 164 | Web Audio API 程序化合成全部音效（`OscillatorNode` + `GainNode` + 噪声缓冲）：射击/命中/玩家受伤/敌人死亡（不同类型不同音调）/脚步声/BGM 环境音。零音频文件。挂载到 `window.audioManager` |
| `OverlayScreen.js` | 98 | 三个覆盖画面：标题（"RAYCASTING" + 操作提示 + "按 Enter 开始"）、死亡（"YOU DIED" + 分数/最高分/新纪录）、胜利（"MISSION COMPLETE" + 分数/最高分） |
| `CommentaryService.js` | 403 | AI 实时解说：12 种游戏事件触发（game_start/wave_start/wave_clear/enemy_kill/player_hurt/health_pickup/low_hp/player_death/victory/new_record/pause/unpause）→ LLM 文本生成（DeepSeek 等 OpenAI 兼容 API）+ 模板兜底（网络不可用时自动降级）→ Web Speech API / 小米 MiMo TTS 朗读。捧哏风格 prompt，带冷却和优先级队列。挂载到 `window.commentaryService` |

## 五、关键技术点

### 1. DDA 射线投射
每帧对屏幕 640 列各发一条射线，在 20×20 格地图中步进检测墙体命中，取**垂直距离**做鱼眼校正（消除广角扭曲），采样纹理列绘制墙条。FOV 约 66°（2 × atan(0.66)）。

### 2. 程序化纹理
所有纹理（64×64）在初始化时用 Canvas 2D 程序化生成：
- 4 种墙面：红砖墙、蓝砖墙、绿石头、橙木头（含砖缝、噪声、渐变）
- 地板/天花板：棋盘格 / 混凝土纹理
- 5 种敌人：不同颜色和造型的像素画
- 医疗包：红色十字

运行时零外部图片依赖。

### 3. 全帧 ImageData 批量写入
墙、地板、天花板、精灵、子弹全部写入同一个 `ImageData.data`（Uint8ClampedArray），最后一次性 `putImageData`。构造时预加载所有纹理列缓存（`_wallColCache`）和纹理 ImageData 缓存（`_pixelCache`），避免每帧 `getImageData` 调用。

### 4. 碰撞检测
- **玩家**：7 点采样（前/后/左/右 + 4 个对角点）+ 分轴检测，支持贴墙滑行
- **敌人**：5 点采样 + 对角点 + 分离力（防重叠）
- **门**：101（横门）、102（竖门），可开关交互

### 5. Web Audio 程序化音效
所有音效用 `OscillatorNode`（正弦波/方波/锯齿波）+ `GainNode` 包络 + `AudioBuffer` 噪声合成，通过 `AudioContext` 播放。BGM 为低频持续环境音循环，脚步声按间隔触发。零音频文件。

### 6. AI 实时解说
事件驱动架构：游戏事件入队 → 优先级 + 冷却判断 → LLM API 调用（可配置 endpoint/key/model）→ 失败时模板兜底 → TTS 朗读（浏览器内置 `SpeechSynthesis` 或小米 MiMo API）。HTML 中有可折叠的设置面板配置 API 参数。

### 7. 精灵渲染管线
所有精灵按与玩家距离从远到近排序 → 透视投影计算屏幕位置和尺寸 → zBuffer 逐列遮挡判定 → 采样纹理像素写入 ImageData（距离衰减 + 雾效混合）。

## 六、游戏玩法

### 核心循环
第一人称射击，在 20×20 地图中消灭敌人、拾取医疗包，撑过 5 波攻击。

### 操作模式

**纯键盘**：
| 按键 | 功能 |
|------|------|
| W/↑ | 前进 |
| S/↓ | 后退 |
| A/D | 左右平移 |
| ←/→ | 左右旋转 |
| Space | 射击 |
| Shift | 加速跑 |
| P | 暂停/继续 |
| Enter/Space | 开始/重开 |

**键鼠**：
| 操作 | 功能 |
|------|------|
| W/↑ | 前进 |
| S/↓ | 后退 |
| A/D | 左右平移 |
| 鼠标移动 | 旋转视角（点击画面锁定鼠标） |
| 鼠标左键/Space | 射击 |
| Shift | 加速跑 |
| P | 暂停/继续 |
| Esc | 解除鼠标锁定 |

### 敌人类型

| 类型 | 颜色 | HP | 速度 | 击杀枪数 | 分数 | 备注 |
|------|------|-----|------|----------|------|------|
| 快速 | 橙 | 50 | 3.0 | 1 | 50 | |
| 普通 | 红 | 100 | 1.5 | 2 | 100 | |
| 幽灵 | 青 | 150 | 1.2 | 3 | 150 | |
| 坦克 | 紫 | 200 | 0.6 | 4 | 200 | |
| 远程 | 绿 | 80 | 0.8 | 2 | 175 | 保持距离射击子弹 |

### 规则
- 每发子弹伤害 50，敌人接触伤害 10（首次立即 + 每 3 秒再次）
- 医疗包拾取 +30HP，满血不捡，每波重生 3 个
- 受伤后 2 秒无敌（血条闪烁提示）
- 波次递增：4→5→6→7→8 敌，第 5 波全灭即通关
- 最高分 localStorage 持久化，破纪录时 HUD + 结束画面提示

## 八、关键依赖关系

```
HTML 加载顺序（必须严格遵守）：
utils.js → textures.js → Background.js → Player.js
→ game/Sprite.js → game/SpriteManager.js → game/Screen.js
→ game/AudioManager.js → game/CommentaryService.js
→ game/Weapon.js → game/Game.js → game/OverlayScreen.js
→ game/GameScene.js → index.js
```

所有模块通过全局类（`window` 无模块系统）通信：
- `window.audioManager` — 全局音频实例
- `window.commentaryService` — 全局解说实例
- `Game` 持有所有子模块引用，通过 `registerAction` 注册按键回调
- `GameScene` 组合 `Player`、`Background`、`Screen`、`SpriteManager`、`Weapon`、`AudioManager`
- `Screen` 读取 `Player` 的位置/方向进行射线投射
- `Sprite`/`SpriteManager` 读取 `Player`/`Background` 进行 AI 寻路和碰撞
