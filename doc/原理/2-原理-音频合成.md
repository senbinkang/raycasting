# 音频合成原理

> 2026-07-06

## 为什么没有音频文件？

所有音效和 BGM 均由 **Web Audio API** 在运行时实时合成，无需任何 .mp3/.wav/.ogg 等外部音频资源。

核心思路：用代码生成声波（正弦波、锯齿波、方波、白噪声），通过振荡器节点（OscillatorNode）和增益节点（GainNode）组合，形成射击声、脚步声、爆炸声等音效。这被称为**程序化音频合成**。

## Web Audio API 基本概念

Web Audio API 是一个音频处理图（Audio Graph），由节点（Node）串联而成：

```
[OscillatorNode] → [GainNode] → [destination（扬声器）]
       ↑                ↑
  频率/波形         音量/衰减
```

- **OscillatorNode**：振荡器，生成特定频率和波形的周期信号
- **GainNode**：增益节点，控制音量（0=静音，1=最大）
- **AudioContext.destination**：最终输出（扬声器）

AudioManager 类持有单例 `AudioContext`，所有音效共用同一个上下文。

## 音效合成详解

### 1. 基础音频单元

```javascript
// 单频音：指定频率、时长、波形、音量
_tone(freq, duration, type = 'sine', volume = 0.3)

// 白噪声：用随机采样填充 AudioBuffer
_noise(duration, volume = 0.3)
```

`_tone` 创建一个 OscillatorNode，连接到 GainNode，设置音量从初始值按指数衰减到 0.001（近乎静音），营造自然衰减而非突然切断的效果。

`_noise` 创建一个 AudioBuffer，用 `Math.random() * 2 - 1` 填充每个采样点，产生白噪声。同样做指数衰减。

### 2. 射击音效（playShoot）

三层叠加：
| 层 | 频率 | 时长 | 波形 | 音量 | 听感 |
|----|------|------|------|------|------|
| 低频主体 | 150Hz | 0.12s | 锯齿波 | 0.4 | "砰"的沉闷感 |
| 噪声叠加 | 白噪声 | 0.08s | — | 0.3 | 爆发感/冲击力 |
| 高频尾音 | 800Hz | 0.06s | 正弦波 | 0.1 | "嗖"的尖锐余韵 |

锯齿波（sawtooth）富含泛音，比正弦波更"粗糙"，适合模拟枪声的爆破感。

### 3. 敌人死亡音效（playEnemyDeath）

单锯齿波做**频率下行滑音**：从起始频率 `exponentialRampToValueAtTime` 滑到 60Hz，模拟"呜——"的下坠感。

不同类型敌人参数不同：

| 敌人类型 | 起始频率 | 时长 | 音量 | 听感 |
|----------|---------|------|------|------|
| 快速（203） | 600Hz | 0.15s | 0.3 | 尖锐短促 |
| 坦克（204） | 120Hz | 0.5s | 0.4 | 低沉悠长 |
| 其他 | 300Hz | 0.3s | 0.3 | 中等 |

### 4. 脚步声（playStep）

低频正弦波 80Hz + 微量白噪声，时长仅 0.08s，音量 0.25。短促轻巧。

`updateStep(dt, isMoving)` 控制播放频率：每 0.4 秒最多触发一次，模拟走路节奏。

### 5. 背景音乐（startBgm）

不是旋律，而是**持续低音环境音**。叠加 4 个正弦波振荡器：55Hz、73Hz、110Hz、147Hz（构成接近 A 大调和弦的低音泛音列），以极低音量（0.06）持续播放。用 `linearRampToValueAtTime` 在 1.5 秒内淡入，避免突兀。

## 延迟初始化与自动恢复

```javascript
_init()   // 首次调用音效时才创建 AudioContext（延迟初始化，节省资源）
_resume() // 浏览器自动暂停 AudioContext 时（如页面失去焦点），调用 resume() 恢复
```

## 关键设计决策

- **零外部依赖**：不依赖任何音频文件，代码即音频
- **单例 AudioContext**：节省资源，浏览器限制 AudioContext 数量
- **指数衰减**：`exponentialRampToValueAtTime` 模拟自然声音衰减，避免"咔嚓"切断声
- **多层叠加**：单一频率太单薄，多层叠加才能产生丰富的音色

|------|------|
| `game/AudioManager.js` | 全部音效合成逻辑 |
