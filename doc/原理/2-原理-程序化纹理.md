# 程序化纹理原理

> 2026-07-06

## 概述

游戏中所有视觉纹理（墙壁、地板、天花板、敌人、物品）均通过 JavaScript 在 `<canvas>` 上**程序化绘制**生成，不使用任何外部图片文件。

核心类：`TextureManager`（`textures.js`），在构造函数中调用 `generateAll()` 一次性生成全部纹理，存入 `this.textures` 字典。

## 纹理规格

- **尺寸**：64×64 像素
- **格式**：HTML Canvas（`<canvas>` 元素）
- **总数**：10 张纹理（4 墙 + 地板 + 天花板 + 4 敌人 + 1 物品）
- **读取方式**：按列读取（`getTextureColumn`，用于墙面）或整张读取（`getPixels`，用于精灵）

## 生成流程

```
new TextureManager()
  └─ generateAll()
       ├─ textures[1]  = generateBrick(200, 70, 70)    红砖墙
       ├─ textures[2]  = generateBrick(70, 120, 210)   蓝砖墙
       ├─ textures[3]  = generateStone(150, 150, 160)  石头墙
       ├─ textures[4]  = generateWood(180, 130, 70)    木头墙
       ├─ textures[10] = generateFloorChecker()        地板
       ├─ textures[11] = generateCeil()                天花板
       ├─ textures[201] = generateEnemy()              普通敌人（红）
       ├─ textures[202] = generateItem()               医疗包
       ├─ textures[203] = generateFastEnemy()          快速敌人（橙三角）
       ├─ textures[204] = generateTankEnemy()          坦克敌人（紫方块）
       ├─ textures[205] = generateGhostEnemy()         幽灵敌人（青椭圆）
       └─ textures[206] = generateRangedEnemy()        远程敌人（绿 + 炮管）
```

## 各纹理生成算法

### 墙壁纹理

#### 砖墙（generateBrick）

```
1. 填充基色（如红色 RGB(200,70,70)）
2. 绘制砖缝网格：
   - 每 8px 一行，水平缝 2px 宽
   - 每 16px 一列，垂直缝 2px 宽（奇偶行错位半块砖）
3. 叠加随机噪声（amount=12，像素值 ±12 的随机浮动）
```

砖缝颜色 = 基色 × 0.4，比基色暗 60%，形成明显的砖块分界。

通过传入不同的基色参数，同一算法产生红砖墙和蓝砖墙两种纹理。

#### 石头墙（generateStone）

```
1. 填充基色（灰 RGB(150,150,160)）
2. 绘制 60 个随机位置、随机大小的半透明圆形斑块
   - 斑块颜色 = 基色 × 随机系数 (0.65~1.05)
   - 半径 = 4~12px
3. 绘制 8 条随机短线（模拟表面裂痕）
4. 叠加噪声（amount=20，较砖墙更粗糙）
```

#### 木头墙（generateWood）

```
1. 填充基色（棕 RGB(180,130,70)）
2. 绘制垂直木板：每 16px 一条，每条颜色略有随机变化
   - 14px 宽木板 + 2px 深色拼缝
3. 绘制水平半透明横纹（每 4px 一条，模拟木纹）
4. 叠加噪声（amount=12）
```

### 地板与天花板

#### 棋盘格地板（generateFloorChecker）

```
1. 绘制 2×2 棋盘格（每格 32×32px）
   - 亮格 RGB(70,70,75)，暗格 RGB(50,50,55)
2. 深色描边 RGB(30,30,30)
3. 叠加噪声
```

#### 天花板（generateCeil）

与地板相同算法，但颜色更亮（亮格 105/暗格 90），模拟上方光源。

### 敌人纹理

所有敌人纹理共享相同的结构模式：
- 背景透明（`clearRect` 清空画布）
- 主体形状（圆形/三角形/方形/椭圆）
- 白色眼睛 + 黑色瞳孔
- 下半部阴影（增加立体感）
- `_addNoise` 增加质感

#### 5 种敌人视觉差异

| 索引 | 类型 | 主体形状 | 颜色 | 特征 |
|------|------|----------|------|------|
| 201 | 普通 | 圆 | 红 RGB(210,50,50) | 锯齿嘴 |
| 203 | 快速 | 倒三角 | 橙 RGB(230,140,40) | 三角形轮廓 |
| 204 | 坦克 | 正方 | 紫 RGB(140,50,200) | 方块 + 矩形嘴 |
| 205 | 幽灵 | 椭圆 | 青 RGB(50,200,200) | 椭圆 + 半透明底部 |
| 206 | 远程 | 圆 | 绿 RGB(60,180,80) | 灰色炮管 + 炮口 |

#### 透明处理

精灵纹理在绘制时使用 `ctx.clearRect(0, 0, size, size)` 清空为全透明，只绘制实体像素。渲染时，3D 视图中的精灵绘制会检查 alpha 通道：
```javascript
if (a < 32) continue  // 透明像素跳过
```

### 医疗包纹理（generateItem）

```
1. 白色方块背景 RGB(235,235,235)
2. 红色十字（竖条 + 横条），组成医疗标志
3. 深灰描边 RGB(80,80,80)
4. 叠加噪声
```

## 从纹理到渲染的数据流

### 墙面纹理：按列读取

```javascript
getTextureColumn(textureIndex, texX)
// 返回：长度为 64 的数组，每个元素 [r,g,b]
// texX 是墙上命中点在纹理中的水平位置（0~63）
// 带缓存，避免每帧 getImageData
```

Screen.js 在构造时预加载所有墙体纹理列到 `_wallColCache`（`Uint8ClampedArray` 格式，去掉 alpha 通道节省内存）。

### 精灵纹理：整张读取

```javascript
getPixels(textureIndex)
// 返回：64×64 的 ImageData（含 alpha 通道）
// 带缓存
```

## 关键设计决策

- **零图片依赖**：所有纹理纯代码生成，项目无需管理图片资源
- **64×64 低分辨率**：配合 640×400 的 3D 视口，纹理采样后经距离衰减，低分辨率不影响最终观感
- **噪声叠加**：每张纹理最后都叠加噪声，避免纯色块的"塑料感"，增加粗糙度和真实感
- **列缓存**：墙面渲染只需纹理的某一列像素，预加载所有列到缓存，渲染时零 `getImageData` 开销

## 涉及文件

| 文件 | 角色 |
|------|------|
| `textures.js` | 纹理生成 + 读取接口 |
| `game/Screen.js` | 预加载纹理缓存 + 渲染时采样 |
